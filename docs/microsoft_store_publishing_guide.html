Microsoft Store Publishing Guide

This guide details the step-by-step process for publishing ExploreDB to the Microsoft Store. It covers building the correct package and navigating the Microsoft Partner Center submission process.

1. Build the Store Package

Before you can publish, you need to generate the unsigned .msix package specifically tailored for the Microsoft Store (which strips out the auto-updater and uses the Store identity).

  1. Open your terminal in the ExploreDB root directory.
  2. Run the build script: scripts\build_store_release.bat
  3. CRITICAL VERSION RULE: The Microsoft Store strictly requires the 4th digit (the "revision" number) of your version to be exactly 0.
    • Valid: 1.0.1.0, 2.4.5.0
    • Invalid: 1.0.0.18, 1.5.0.3
    • If you need to bump the version, use scripts\publish_new_release.bat and ensure the version ends in .0.
  4. The script will output the final package into the StoreRelease folder (e.g., ExploreDB.msix).

2. Create a New Submission in Partner Center

  1. Log in to the Microsoft Partner Center.
  2. Navigate to your ExploreDB app.
  3. Click on Start your submission (or edit an existing draft).

You will see a checklist of sections that need to be marked as Complete.

Section A: Pricing and availability

  • Set the price of the app (Free or Paid).
  • Choose the markets where the app will be available (usually all).
  • Click Save draft.

Section B: Properties

  • Category and subcategory: Select Developer tools > Database.
  • Privacy policy dropdown:
  • If the Partner Center allows it, select No, my product doesn't use any personal information.
  • Note: Because ExploreDB uses the runFullTrust and networking capabilities, Microsoft's automated scanners might force this dropdown to Yes... and require a Privacy Policy.
  • Privacy Policy Text: If forced to provide a policy, select the Provide privacy policy text option and paste:

"ExploreDB does not collect, store, or transmit any personal data, telemetry, or analytics. All database connections and queries are executed directly between your local machine and your database servers."

  • Click Save draft.

Section C: Age ratings

  • App Type: Select All Other App Types.
  • Click Save and continue.
  • You will be presented with a questionnaire asking if the app contains violence, social content, gambling, location sharing, etc.
  • Answer No to every single question on the page.
  • Click Save draft to instantly receive an "E for Everyone" (3+) rating.

Section D: Packages

  • Device family availability: Check the box for Windows 10/11 Desktop. (Leave "Let Microsoft decide..." checked as well).
  • Upload: Drag and drop your ExploreDB.msix (from the StoreRelease folder) into the grey upload box.
  • Troubleshooting Uploads:
  • Stuck on Validating...: There is a known bug in Partner Center where the UI spins forever with a Status: OK, FaultCode: undefined error. Simply press F5 to refresh the page, and the package will usually appear as successfully uploaded.
  • runFullTrust Warning: You will see a yellow warning stating: The following restricted capabilities require approval... runFullTrust. This is normal and expected for desktop database apps. Ignore the warning and proceed.
  • Click Save draft.

Section E: Store listings

  • Click the blue link for your language (e.g., English (United States)).
  • Description: Enter a detailed description of ExploreDB's features.
  • Screenshots (Mandatory): Upload at least 1 screenshot of the app in action (must be .png, 16:9 aspect ratio recommended).
  • Store logos (Mandatory): Scroll down to "Store display images" and upload exactly one 1:1 App logo (300 x 300). It must be exactly 300x300 pixels and in .png format.
  • Optional fields: You can also provide a Short Description and Keywords (SQL, Database, Client) in the Supplemental/Additional information sections.
  • Click Save draft.

Section F: Submission options

Because ExploreDB is a desktop app utilizing the runFullTrust capability, you must provide a one-sentence justification.

  • Locate the red text box asking: "Why do you need the runFullTrust capability, and how will it be used in your product?"
  • Paste the following justification:

"ExploreDB is a WinUI 3 desktop application that requires full trust to establish network connections to local and remote SQL database servers, and to save user configuration files to the local disk."

  • Click Save draft.

3. Submit for Certification

Once all sections on the main checklist say Complete, the Submit for certification button at the top right will unlock. Click it to send your app to Microsoft for review! Reviews typically take 1 to 3 business days.
